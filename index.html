EXPRESSION GUIDE

How to use

  • 5! calculates factorial.
  • sum(i=1..5, i) adds values from 1 to 5.
  • product(i=1..4, i) multiplies values from 1 to 4.
  • doubleSum(i=1..3, j=1..2, i+j) performs double summation.
  • doubleProduct(i=1..3, j=1..2, i+j) performs double product.
  • log(100) is base-10; log2(8) is binary logarithm.
  • Use ^ for exponents and % for modulo.
  • Use floor(), ceil(), and intdiv() for basic operations.
